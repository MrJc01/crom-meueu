# 01 - Vision & Philosophy

## A Filosofia: "Backend como Plataforma"
Ao contrário das redes tradicionais onde o frontend dita as regras, aqui a API é Soberana.

### O Objetivo
Fornecer uma estrutura robusta de dados relacionais ("Nodes") e deixar a comunidade criar os clientes (um clone do TikTok, um leitor de blog minimalista, um terminal CLI, etc.), todos consumindo a mesma base.

### Inspiração
O modelo do TabNews (focado em conteúdo e reputação), mas expandido para ser agnóstico ao tipo de mídia.

## Moderação e Governança
Implementaremos Moderação Distribuída baseada em Reputação para garantir a saúde da comunidade sem dependência central excessiva.

### Trust Score
Usuários ganham pontos por contribuições úteis.

### Poder de Polícia
Usuários com pontuação X podem ocultar spam ou banir bots temporariamente. A comunidade se auto-regula.

### API de Moderação
Expor endpoints de denúncia para que bots de IA (seus agentes) possam ajudar a filtrar toxicidade automaticamente.
